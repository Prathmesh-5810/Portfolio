## 🚀 Key Features & Interactive Capabilities

### 3D Animation & Interaction Engine

- **⚡ Scroll Progress Bar:** Fixed top indicator tracking scroll depth through the page
- **🎯 Cursor Glow Effect (Desktop):** Real-time radial glow following mouse coordinates on large screens
- **🃏 3D Card Tilt System:** All glass cards respond to mouse movement with:
  - Dynamic rotation (`rotateX`, `rotateY`) based on cursor position
  - Glare overlay effect for depth perception

- **✨ Border Beam Animation:** Traveling gradient animation on all project and certification cards

- **🔢 Number Counter Animation:** Statistics animate from 0 to target on scroll into view
- **📍 Timeline Illumination:** Experience timeline dots highlight as you scroll past sections
- **🧭 Active Navigation Spy:** Navigation links highlight based on scroll position
- **♿ Motion Accessibility:** All animations respect `prefers-reduced-motion` media query

- **🔥 Red-Orange Neon Accent:** Name gradient and key interactive elements
- **💎 Glassmorphism:** All cards with 10px backdrop blur and refined borders

### JavaScript Modules
- **Mobile Menu Toggle**: Controls hamburger button and nav links active states.
- **Navbar Sticky Effect**: Adds backdrop shadow and darkening on scroll past 50px.
- **Active Navigation Spy**: Tracks scroll position against section IDs to update active links.
- **Scroll Progress Bar**: Updates width based on scroll depth percentage.
- **Intersection Observer Animations**: Observes `.fade-in-up` elements with improved threshold detection; triggers 3D rotation entrance and stat counter on view.
- **Number Counter Animation**: Animates statistics from 0 to target value on About section scroll into view.
- **Desktop Cursor Glow**: Tracks mouse movement and positions cursor glow effect (desktop only, respects motion preferences).
- **3D Card Tilt System**: Per-card mouse tracking calculates `rotateX` and `rotateY` transforms based on cursor position relative to card center; updates CSS variables for real-time 3D rotation and spotlight positioning.
- **Magnetic Button Effect**: Cursor proximity tracking within 150px threshold; buttons translate smoothly toward cursor and scale up.
- **Hero Parallax Effect**: Floating layer translation on mouse movement; only active when hero section is in viewport.
- **Timeline Scroll Illumination**: Highlights timeline dots as they scroll into viewport (scroll event listener).

